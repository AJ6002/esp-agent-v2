## Configuration

| Variable | Purpose | Required | Default |
|----------|---------|----------|---------|
| `DATABASE_URL` | SQLAlchemy PostgreSQL connection URI | Yes | `postgresql+psycopg://postgres:postgres@localhost:5432/industrial_maintenance` |
| `REDIS_URL` | Redis connection URI | No | `redis://localhost:6379/0` |
| `SECRET_KEY` | JWT signature key | Yes | Random secure secret |
| `AI_ENABLED` | Toggle proprietary AI LLM integration | No | `false` (uses built-in deterministic Mock LLM) |
| `OPENAI_API_KEY` | API key for OpenAI-compatible LLM provider | Optional | `""` |
| `OPENAI_BASE_URL` | Base URL for LLM provider API | Optional | `https://api.openai.com/v1` |
| `GATEWAY_ENABLED` | Industrial OPC UA gateway polling toggle | No | `false` |
| `GATEWAY_MODE` | Ingestion mode: `mock` or `opcua` | No | `mock` |
| `GATEWAY_ENDPOINT` | OPC UA server endpoint URL | No | `mock://opcua-simulator` |
| `GATEWAY_SUBSCRIPTION_ENABLED` | Enable OPC UA event-driven subscriptions | No | `false` |
| `OTEL_ENABLED` | Enable OpenTelemetry tracing pipeline | No | `false` |
| `SEED_ON_STARTUP` | Seed initial demo equipment, users, SOPs on launch | No | `true` |
